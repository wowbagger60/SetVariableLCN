# SetVariableLCN

[Deutsch](README.de.md) | English

IP-Symcon library by Ueli Schweizer / Cassanis Automation.

| Module | Description |
|---|---|
| [SetVariableLCN](SetVariableLCN/README.md) | Writes values reliably into LCN variables (control loop with relative commands) |

## Requirements

IP-Symcon 8.0 or later with Symcon's LCN module (LCN Value).

## Installation

Via the Module Store or in Module Control with the URL
`https://github.com/wowbagger60/SetVariableLCN`.

## Development

`tests/SetVariableLCN-Test.php` is a Symcon script for a test installation with
two LCN modules. Adjust the constants at the top of the script.
