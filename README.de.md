# SetVariableLCN

Deutsch | [English](README.md)

IP-Symcon-Bibliothek von Ueli Schweizer / Cassanis Automation.

| Modul | Beschreibung |
|---|---|
| [SetVariableLCN](SetVariableLCN/README.de.md) | Schreibt Werte zuverlässig in LCN-Variablen (Regelkreis mit relativen Befehlen) |

## Voraussetzungen

IP-Symcon ab Version 8.0 mit dem LCN-Modul von Symcon (LCN Value).

## Installation

Über den Module Store oder im Module Control mit der URL
`https://github.com/wowbagger60/SetVariableLCN`.

## Entwicklung

`tests/SetVariableLCN-Test.php` ist ein Symcon-Skript für eine Testanlage mit
zwei LCN-Modulen. Konstanten oben im Skript anpassen.
